# VASMU - A Simple Modern Calculator 🧮

Hey there! Welcome to my calculator project. I wanted to build something clean, straightforward, and actually useful, so I put together this responsive web calculator. It handles your everyday math but also has built-in shortcuts for quickly figuring out rectangle geometry.

## 🚀 Check It Out
You don't need to install anything or run any complicated setup commands. Just download the `index.html` file, double-click it, and it will open right up in your favorite web browser.

---

## ✨ What It Can Do

- **The Basics:** Addition, Subtraction, Multiplication, and Division.
- **Extra Math Ops:** Modulo (`%`) for remainders and Exponentiation (`**`) for powers.
- **Geometry Shortcuts:** 
  - **Area of a rectangle** (just pass length as Num1 and width as Num2).
  - **Perimeter of a rectangle**.
- **Foolproof Inputs:** It won't crash if you leave a box empty or accidentally type letters—it'll politely remind you to enter valid numbers.
- **No Demolition by Zero:** If you try to divide by `0`, it breaks gracefully and shows an error message instead of breaking the page.
- **Under-the-hood Logs:** If you like playing around with the DevTools console (`F12`), you'll see a clean printout of your input values and the final answer.

---

## 🛠️ How I Built It

I kept this project super lightweight by putting everything into a single file using:
*   **HTML5** for the core layout.
*   **CSS3** for the clean blue accents, shadows, and smooth card layout.
*   **Vanilla JavaScript** to handle the math logic instantly on click.

---

## 💻 Running It on Your Machine

1. Grab the code or download the files.
2. Find `index.html`. 
3. Open it up using Google Chrome, Safari, Firefox, or Edge.
4. Type in your numbers, pick your operator, and hit **Calculate**!
